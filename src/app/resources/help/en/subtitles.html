Automatic subtitles from speech

LumoraStudio can listen to the speech in your video and write it as subtitles. Recognition runs on this computer; the sound is never sent anywhere.

  1. Choose Edit → Subtitles → Automatic subtitles from speech….
  2. Pick the Spoken language (or Detect automatically if you don't know).
  3. Pick a Model: Fast, Balanced or Most accurate. More accurate models are slower. The model is downloaded once, the first time.
  4. Subtitles: As spoken or Translated into English. The same model translates on this computer; the larger models translate better.
  5. Press Write subtitles. They are written to a new subtitle track.
  6. Play it back and fix any misheard words (see below).

Writing subtitles yourself

  1. Put the playhead where the speech starts and choose Add subtitle (Shift+T).
  2. Type what is said in Properties. Two lines at most read best.
  3. Set its timing by dragging its edges on the timeline.

A subtitle track's language (Language, e.g. eng) and look (text size, dark box, position) are set in Properties. For several languages, add several subtitle tracks with Edit → Subtitles → Add subtitle track.

Import and export

  • Import subtitles (SRT, VTT)… loads a subtitle file onto a new track.
  • Export subtitles… saves them as an .srt or .vtt file.
  • When exporting the video you can embed the subtitles, burn them into the picture or save them next to it as .srt. See Exporting.
